# Zaxis

A simple 3D model viewer based on the [Sketchfab Viewer API](https://sketchfab.com/developers/viewer).

Live Demo: https://ninko-cc.github.io/zaxis/

## Usage

You can view any Sketchfab model by appending its Model ID to the URL.

1. Find the Model ID from the Sketchfab URL: `https://sketchfab.com/3d-models/<model-id>`

2. Use it in Zaxis like this: `https://ninko-cc.github.io/zaxis/?model=<model-id>`
